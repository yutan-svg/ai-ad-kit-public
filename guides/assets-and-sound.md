# 素材の作り方（登場人物と音）

制作の手順は `guides/production.md`、判断の基準は `RULES.md` にあります。ここは素材そのものの作り方です。

- [1. 登場人物の素材を揃える](#1-登場人物の素材を揃える)
- [2. 音の設計](#2-音の設計)

---

## 1. 登場人物の素材を揃える

**要点**: 広告と LP で繰り返し使う人物は、**権利がはっきりした自社生成**に統一し、共通スタイルを1つ決めて動かしません。
配布サイトの無料素材は、それを基にした AI 生成や改変が認められていないことが多くあります。

**共通スタイル**（値は案件ごとに決めてよい。決めたら動かさない）: 絵柄／線／塗り／印象／目の大きさ／
体型（頭身 1:6 前後の大人の比率。デフォルメ化は禁止）／構図（全身）／背景（完全に透明）／出力サイズ（1024×1536px）。
スタイルを固定するため、**権利がはっきりした自社の素材を3〜5枚**だけ絵柄の基準として渡します。

**登場人物は役割から決めます**（見た目からではなく）。同じ立場の人物を2人出すときは、顔立ち・髪型・服の色で
**別人とすぐ分かる差**を必ずつけます。**ポーズ**は主要な人物で6〜7、脇役で2〜3が目安です（基準姿勢／困り／笑顔／
疑問／驚き／達成感／指差し／思案／自信なさげ／案内）。「笑顔」と「達成感」は混ざりやすいので、
**穏やかさと力強さ**で明確に差をつけます。置き場所は `assets/images/characters/`、命名は `<人物ID>_<ポーズ>.png`。

**生成の進め方**: 全工程を同じチャットの中で続けて進めます（造形と絵柄が保たれるため）。
**基準姿勢の1枚目が最重要**で、合格が出るまで3〜5回作り直してかまいません。**1メッセージ1枚**を守ります
（複数枚を頼むと1枚に複数人を並べて描かれます）。出力の指定（サイズ・透過 PNG・全身）は毎回付けます。

| 症状 | 言い直しの要点（英語のまま有効） |
|---|---|
| 頭身が縮む | `Use realistic adult proportions, 1:6 head-to-body ratio. No chibi or deformed style.` |
| 顔や服が変わる | `Keep the exact same face, hair, clothing, and proportions as the previous image. Only the pose and expression should change.` |
| 背景が出る | `Background must be completely transparent. Output as transparent PNG with no background, no white fill.` |
| 上半身しか出ない | `Show the full body from head to feet, including the shoes.` |
| 2人が似すぎる | `Make this character clearly distinguishable — different hairstyle, face shape, and clothing color.` |

検収が終わったら、**人物とポーズの一覧をファイル名つきで `knowledge/assets.md` に書き戻します。**

## 2. 音の設計

**要点**: ファイルの長さ ≠ 鳴っている長さ。**必ず実測**します。効果音は**対象の語の頭**に合わせ、余韻は最後まで鳴らします。
音を足さない判断も設計のうちです。

```bash
ffmpeg -hide_banner -i "<音源ファイル>" -af "silencedetect=noise=-40dB:d=0.05" -f null - 2>&1 | grep silence
```

見るのは2つ。**先頭の無音**（あると「間が遅い」と感じられるので `<Audio startFrom={N}>` で補正）と、
**実音の終わり**（余韻を含めて消えきるまで）。測った値は `knowledge/assets.md` に残します。

**置く位置は2択**です（シーンの頭に固定で置くと、何を指しているのか意味が濁ります）。
①**対象の語の頭と同時**＝数字・金額・キーワードの強調。単語レベルの実測時刻で位置を取る。
②**言い終えた直後**（フレーズの終わり＋2〜5フレーム）＝要点を確定させる打音、話題の切り替え。

**尾を切らない。** シーンの尺を「発火点＋実音の終わり」まで延長します
（例: 実音1.9秒＝30fps で 56 フレームの効果音を 180 フレームで鳴らすなら、そのシーンには 236 フレーム以上が必要）。
シーンの音声そのものは、末尾 130ms 程度のフェードアウトをかけます（部屋の音が急に切れると「ぶち」と聞こえます）。

**音量の基準**: ナレーション 1.0 ／ キラキラ系 0.5〜0.65 ／ 切替の効果音 0.4〜0.5 ／ 一瞬の効果音 0.6〜0.8 ／
BGM（リズム系）0.10〜0.20 ／ BGM（旋律系）0.20〜0.30。喋り続ける動画に旋律のある BGM は情報過多になります。

| シーンの意図 | 当てる音の種類 | 音量 |
|---|---|---|
| 数字・金額の強調、値が確定する | 上昇するキラキラ音（余韻あり） | 0.5〜0.65 |
| 1行ずつ現れる列挙、下線が引かれる | 短いキラン音（余韻なし） | 0.5 |
| 要点を1つ確定させる、話題の切り替え | 打音（ポン・カチッ） | 0.4〜0.5 |
| 冒頭の不安、ネガティブへの転調 | 低い鐘・低音 | 0.18〜0.4 |
| 明るい展開への転換 | ファンファーレ／上昇キラキラ音 | 0.45〜0.6 |

**足さない設計**: ひそひそ話・本音の告白は効果音なし＋BGM を止める。謝罪・共感の間は効果音なし＋BGM を 25% 程度に下げる。
BGM を止めること・下げることも、タイムラインに明示的に書きます。

**効果音と BGM は、選ぶ前に `knowledge/sound-catalog.md` を読みます。** 音の性格・向く場面・実音の長さ・配布元と利用条件（同梱の可否）が書いてあります。ファイルは同梱していないので、担当者に配布元からダウンロードしてもらいます。

**効果音の中身はファイル名から分かりません。** AI は音を聴けないので、名前から推測して仮に置き、
依頼主に聴いてもらって微調整する、という順番で段取りを組みます。対応表は1箇所に集約します（`RULES.md` 決まり30）。
