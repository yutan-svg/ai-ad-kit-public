# talking-head — 音声を先に作って「話すだけの動画」を1本つくる

## 使う場面

- 声（高さ・話す速さ・落ち着き）を自分で選びたいとき
- 人がひと続きに話す画がほしいとき（セリフごとに切り替えない）
- 漢字の読み違いが `takes` の辞書でも直らないとき

**手順の全体・制約・つまずいたときの対処は `guides/production.md` の「4. 音声先行のトーキングヘッド」にあります。先に読んでください。**

**入る前に** `knowledge/project.md` §3 の3つ（①画面に出るのは誰か ②冒頭は誰の・どんな場面から始めるか
③最後にしてほしい行動）が埋まっているか確かめます。空欄なら依頼主に聞いてください。
①が決まっていないと人物の指定が書けず、1本目からやり直しになります。
決めかねているなら `ad-research` を勧めます。LP から推し量って自分で決めないでください。

## 手順

### 1. 聞き取る（一度に3つまで）

1. **台本**（2〜30秒に収まる長さ。収まらなければ文の切れ目で分ける）
2. **人物**（性別・年齢層・服装・姿勢）と**背景**（場所・後ろに写るもの）
3. **声の希望**（落ち着き・速さ・男女）

聞き取った人物と背景は、こちらで英語の説明文に直して `--person` / `--background` に入れます。

### 2. 読み上げ音声を作る

```bash
cp tts.json.example tts.json
python3 scripts/generate_tts.py --script tts.json --dry-run
python3 scripts/generate_tts.py --script tts.json
```

読み上げには**読み方の辞書が効きません。** 読み違う語は、台本側の表記を開いて（漢字をひらがなにして）ください。
依頼主が別の読み上げサービスで作った mp3 を持っている場合は、それを `assets/audio/` に置いてもらえば足ります。

### 3. 送信内容を確かめる（費用はかからない）

```bash
python3 scripts/generate_talking_head.py --audio-file assets/audio/narration.mp3 \
  --person "..." --background "..." --dry-run
```

音声の長さ（2〜30秒）・プロンプトの文面・保存先を確かめます。長さが範囲外ならここで止まります。台本を削る／分けるところからやり直してください。

### 4. 音声を公開URLにする（AI が行う。依頼主の操作は不要）

参照音声はファイルの中身のままでは送れません。

```bash
python3 scripts/rehost.py assets/audio/narration.mp3     # URL を作り、200 を確かめて表示する
```

Google ドライブの直リンクでも構いません。どちらでも **200 が返ることを確かめてから**渡します。
生成が終わったら `python3 scripts/rehost.py --stop` で公開を止めてください。

### 5. 何を・何本・どのサービスで作るかを伝えて承諾を記録する

```bash
python3 scripts/approve.py --generation --ids talking-head --takes 1 --service seedance \
  --note "narration.mp3（12秒）から、人が話すだけの映像を1本"
```

作るもの・本数・サービスを表示して y/N を聞き、記録します。`--note` には、`lines.json` に無いものの内容
（台本や参照音声）を1行で書きます。**記録が無ければ生成は動きません。** この記録を自分で書いてはいけません。

### 6. 生成する（ここから費用がかかる）

```bash
python3 scripts/generate_talking_head.py \
  --audio-url "<公開URL>" --audio-file assets/audio/narration.mp3 \
  --script "（参照音声で読み上げている台本をそのまま）" \
  --person "..." --background "..." --take t1
```

- **1本ずつ**作ります。まとめて走らせないでください
- `--script` は既定で付けます。固有名詞や造語が出力で一般的な語に置き換わるのを防ぎます
- **発音の指示を `--extra` に書かないでください。** `--extra` は英語の短い1文だけです
- **同じ失敗での作り直しは2回まで。** 3回目は台帳（`out/takes-ledger.json`）を見てスクリプトが拒否します。
  拒否されたら `--force` を探す前に、原因（台本・参照音声・プロンプト）を直してください

### 7. 確かめて報告する

自分で先に確かめてから見せます。

| 見る・聴く場所 | 落ちていたら |
|---|---|
| 台本どおりに読めているか | 参照音声そのものを聴き直す。音声側が原因なら読み上げから作り直す |
| 声と口がずれていないか | テイクを変える |
| 姿勢が崩れていないか | `--person` に姿勢を書き込んで1回だけ作り直す |
| 文字・ロゴ・別の人物が入っていないか | プロンプトの否定文が消えていないか確かめる |
| 尺 | 元の音声と少し変わります（仕様）。テロップは**出力された音声**に合わせます |

固有名詞は `python3 scripts/asr_gate.py` で1語ずつ確かめ、さらに `python3 scripts/ear_check.py` で依頼主の耳の判定を取ります。
報告には、置き場所・秒数・気づいた粗さを書きます。**隠さないでください。**

### 8. 配線する

`src/scenes.ts` に1シーン1行で足し、`nativeAudio: true` でクリップの音声を使います。
1本のクリップを複数のシーンに割ってテロップを切り替える形が普通です。この形も `npm run align` の整列の対象になります。
