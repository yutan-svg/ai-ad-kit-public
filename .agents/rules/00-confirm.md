# 先に伝えて、承諾を得てから実行する

このフォルダでは、次の3つを**先に人へ伝えて、はっきりした承諾を得てから**実行します。

1. **費用のかかる生成**（映像・読み上げ・参照画像）— 何を・何本・どのサービスで作るかを伝える
2. **動画ファイル（mp4）の書き出し** — 何を書き出すかを伝える
3. **同じところの作り直し** — 何が起きていて、何を変えて作り直すかを伝える

承諾は `python3 scripts/approve.py` が対話で聞いて記録します。記録が無ければ生成も書き出しも動きません。
**承諾と耳の確認の記録（`out/` の json）を、自分で書いてはいけません。**
返事が承諾なのか感想なのか曖昧なときは、進めずに聞き返してください。確認のために mp4 を書き出さないでください。

役割と手順の入口は @GEMINI.md、制作の決まりは @RULES.md にあります。
