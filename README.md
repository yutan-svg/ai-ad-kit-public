# AI 動画広告 制作キット

30秒〜1分の縦型（9:16 / 4:5）動画広告を、**チャットで相談しながら**作るための一式です。横型（16:9）も作れます。
動画編集の経験も、AI エージェントの知識も要りません。**このフォルダを開いて、話しかけるだけ**で始まります。
開く場所は4つのうちどれでも構いません——**Claude デスクトップアプリ**／**ChatGPT デスクトップアプリ**／**GitHub Copilot**（VS Code のエージェント機能か CLI）／**Antigravity**（Google の開発環境）。Microsoft 365 Copilot はフォルダを開いて道具を動かす機能が無いため対象外です。
どれで開いても、作り方・決まり・検査は同じです。

使い方の説明（何ができるか、どう進むか、何を用意するか）は教材サイトにあります。

**https://marketing-capital.com/kit/**

---

## 始め方

このフォルダを開いて、次のように話しかけてください。

**Antigravity で始める場合**（Google の製品だけで作りたいときはこちら）

1. <https://antigravity.google/download> からインストールします（macOS は 12 以降）
2. 左のサイドバーの「フォルダに＋」のアイコン →「New Project」→ **Add Folder** でこのフォルダを選び →「Create」
3. チャット欄に話しかけます

Google の製品だけで作る手順（参照画像 → 映像 → 検品 → 読み上げ）は `guides/google-models.md` にあります。


> このフォルダで動画広告を作りたいです。何から始めればいいですか。

こうなります。

1. AI が最初の準備を進めます（動画編集ツールの取得など。「準備をしてください」と頼めば順にやります）
2. AI が**商材のことを聞き取ります**（何を売るか・誰に・言ってよいこと／いけないこと・必須の表記）
3. 台本を決めて、映像と音声を作り始めます

あとは聞かれたことに答えていけば進みます。専門用語が出てきたら「分かりません」と言ってください。言い換えて説明します。
**素材のフォルダ（`assets/`）は空の状態で届きます。** 作ったものがここに入っていきます。

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `CLAUDE.md` / `AGENTS.md` / `GEMINI.md` | AI への指示書。3つは同じ内容で、開いたアプリによって読まれるものが変わります |
| `RULES.md` | 制作の流れと、守る決まり |
| `guides/` | 作り方ごとの手順書。AI が必要なときだけ開きます |
| `knowledge/` | この案件のこと（商材・言ってよいこと・素材の台帳・進み具合）。最初に AI が聞き取って埋めます |
| `scripts/` | 検査と生成の道具 |
| `src/` | 動画の組み立て（動画編集ツール Remotion のファイル） |
| `assets/` | 映像・画像・音声の素材（最初は空です） |
| `out/` | 書き出した動画と、承諾・確認の記録 |
| `out/research/` | 広告のリサーチの資料（HTML と画面の写し）。**頼んだときだけ**作られます |
| `FIXES.md` | 直してほしいことの台帳。言ったことが1行ずつ残ります |
| `.claude/` | AI が使う手順書と、確認役のエージェント |
| `.agents/` | 上と同じ中身の、Antigravity 用の写し（機械で同期します。手で編集しません） |
| `.github/` | GitHub Copilot 用の指示（`AGENTS.md` を読むよう案内するだけの短い文書） |
| `.env.example` | 使うサービスの鍵を入れるひな形。`.env` という名前でコピーして使います |

## AI が必ず立ち止まる場面

この5つは、**AI が自分だけでは先に進めない作り**になっています（言葉の約束ではなく、道具の側で止まります）。

| 場面 | 何を聞かれるか |
|---|---|
| 映像や音声を作るとき | 何を・何本・どのサービスで作るか（ここから費用が発生します）→ はい／いいえ |
| 動画ファイルを書き出すとき | どの動画を書き出すか → はい／いいえ |
| 数字や固有名詞が入ったセリフ | その語の部分だけを切り出した音を聴いて、A / B / どちらも不可 を選ぶ |
| 同じところを3回目に作り直すとき | 止まります。何を変えるかを決めてから進みます |
| 聞き取った内容が `knowledge/` に書かれていないとき | 止まります。会話で答えたことは AI がファイルに書き、それが無いと調べる・作る・書き出すに進めません |

返事が「いいですね」だけだと、承諾なのか感想なのか分からないことがあります。その場合は AI がもう一度聞き返します。

映像・音声の生成は**従量課金**です（作った分だけかかります）。実際の金額は各サービスの請求画面で確認してください。

## 直してほしいところが出たとき

そのまま言葉で伝えてください。AI が `FIXES.md` に1行ずつ記録し、直して、確かめてから報告します。
完了の印（✅）を付けるのは、確認したご本人だけです。AI は自分で付けません。

## 見た目を変えたいとき

**フォントは変えられます。** 既定は Noto Sans JP ですが、「〇〇というフォントに変えて」と頼めば、
Google Fonts にある日本語フォントか、お手元のフォントファイル（`assets/fonts/` に置きます）に差し替えます。
テロップの色・大きさ・位置も同じように言葉で頼めます。

---

## 新しい版を受け取ったら

キットは改良されていきます。新しい版を受け取ったときの入れ替え方は `guides/update.md` にあります。
「キットを新しい版に入れ替えてください」と頼めば、AI が進めます。案件の内容（`knowledge/`、`src/scenes.ts`、`assets/`、`FIXES.md`）は残ります。
