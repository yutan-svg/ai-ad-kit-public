# この案件のこと

制作を始める前に、AI が聞き取って埋めます。**空欄のまま制作に入ってはいけません。**
言ってよいことと必須表記が決まっていないと、作ったものを捨てることになります。

記入例はすべて**架空の商材**です。そのまま使わず、案件の実際の内容に置き換えてください。

## 4. この業種にかかる規制

広告表現には**4つの層**の縛りがかかります。4つとも確認してから訴求を決めます。

| 層 | 中身 | 確認先 |
|---|---|---|
| ① 全業種に共通の法令 | 景品表示法（優良誤認・有利誤認・二重価格・打消し表示）、特定商取引法、著作権・肖像権 | 所管官庁の一次情報 |
| ② 業種ごとの法令・ガイドライン | 業種により所管も内容も違う | **案件開始時に一次情報で確認して下の表に書く** |
| ③ 媒体の審査ポリシー | 配信面ごとの禁止・制限。法令上よくても媒体で駄目なことは普通にある | 各媒体のポリシーページ |
| ④ 取引先・提携先のルール | ブランドガイド、提携プログラムの表記義務 | 契約書・提携先の規約 |

②は業種ごとに違うので、キットの側には書きません。調べて、**根拠と確認日をセットで**書いてください。「たぶんこうだろう」は書かないでください。

## 6. 条件つきで言えること

使ってよいが、条件を落とした瞬間に駄目になるものです。

| カテゴリ | 何に注意するか | つける条件 |
|---|---|---|
| 金額・差額 | 特定の事例の数字を全員の話にしない | 「一例です」の注記を前提に扱う |
| 事例 | 想定の事例なら、想定と分かる文脈を保つ | 「イメージです」の明示 |
| 時間・手間の削減 | 条件が揃った場合の話を、全員に起きるように書かない | 「場合があります」「最大」 |
| 利用者の声 | 実在しない声を作らない。業種によっては体験談自体が不可（§4） | 出典を出すか、使わない |
| 期限・希少性 | 事実の期限だけを書く。作った締切は書かない | 実際の終了日を明示 |

断定を避ける3語: **「可能性」「最大」「場合があります」**。

## 7. 使わない表現

理由まで覚えてください。理由が分かっていれば、この表に無い新しい言い回しも自分で判断できます。

| 型 | 例 | なぜ駄目か |
|---|---|---|
| 断定 | 絶対／必ず／確実に／誰でも | 保証できないことを保証したことになる |
| 煽りの期限 | 今だけ／今なら特典（事実でない場合） | 事実でない有利さの演出 |
| 比較優良 | どこよりも優れている／No.1（根拠なし） | 根拠のない優位性の主張。実在他社との比較も避ける |
| 過大な約束 | 必ず◯◯得する／放置すると必ず大損する | 特定の事例を全員の話にしている |
| サービスの性質の誤認 | 実際の仕組みと違う呼び方 | 受け取るものを取り違えさせる。提携先の基準にも反しやすい |
| 利用意思のない申し込みの誘発 | 資料請求だけでもよい／その後の連絡はしなくてよい | 獲得数だけ増えて成果は悪化する |
| LP に無い主張 | LP に書かれていない機能・条件を足す | 広告と LP が食い違う。審査でも落ちる |

## 8. 数字を出すときの決まり

数字は最も強く、最も危険です。出す数字は全部この手順を通します。

1. 一次情報で裏を取る（まとめ記事・競合の広告を根拠にしない）
2. 図やテロップの中に出典を入れる（画面から出典が消えた瞬間、根拠のない数字になる）
3. いつ時点の話かを書く
4. 自社のデータを出すなら、集計の条件を書けるものだけにする
5. 音声の検品で読み間違いを確かめる（単位の落ちも見る）

## 9. 画面に出す表記（必要な場合のみ）

**機械的に全部入れるものではありません。** 要否をこの表で決めます。

| 表記 | 要否 | 必要になるのはどんなときか | 文言 | 出す場所 |
|---|:---:|---|---|---|
| 広告であることの表記 | | アフィリエイト、第三者による推奨、広告主と表示者が違うなど、**広告と分かりにくい形で出すとき** | 【PR】 | |
| 運営者・広告主の表記 | | 誰が出している広告か画面から分からないとき | 【運営】 | |
| AI 生成の素材を使った旨 | | AI が作った映像・画像・音声を使ったとき | ※AI生成映像を使用しています | 該当するカットに |
| 演出であることの注記 | | 実際の画面・実績と違う見せ方をしたとき | ※画面はイメージです | 該当するカットに |
| 条件・注意事項の打消し表示 | | 条件つきの訴求をしたとき | | **読める大きさ・十分な表示時間で** |

自社が自社の商材を出すだけの動画で、誰が出しているか画面から明らかなら、上2つは不要なことがあります。
**迷ったら、要否の根拠（どの規約・どの法令のどこ）をここに書いてください。**「たぶん要る」で機械的に足さないでください。

文言を決めたら、`src/brand.ts` の `BRAND` / `OPERATOR` / `FOOTER_NOTES` に反映します（空にすれば描かれません）。
小さすぎる・一瞬だけの打消し表示は、打消しとして認められません。注記はテロップより小さく、ただし読めない大きさにはしません。

## 10. 読み方の登録

商材名や固有名詞に読み違いが起きる語があれば、`knowledge/pronunciation.json` を作って登録します
（このファイルが無ければ無視されるので、必要になってから作れば足ります。キットを新版に差し替えても残ります）。

```json
{
  "entries": [
    {
      "surface": "（台本に出る表記）",
      "replace": "（台本内で置き換える表記。置換しないなら null）",
      "reading": "（音声認識の結果を正規化するための読み）",
      "guide": "（英語の発音指示。誤読の候補を never 〜 で名指しで並べる）"
    }
  ],
  "asr_variants": {"（音声認識が返しがちな当て字）": "（正しい読み）"}
}
```

書き方の見本は `scripts/pronunciation_dict.json` にあります。1テイク目が誤読したら、その誤読を `guide` の `never` に足してから2テイク目を投げてください。
